# @0x1audio/sdk

The TypeScript SDK for Mixel apps: the typed way into Mixel from an app's page (`@0x1audio/sdk/page`), and a client for the Mixel API.

```ts
import { ox } from "@0x1audio/sdk/page"
```

The guides and the reference are at [docs.0x1audio.com](https://docs.0x1audio.com). To work on the SDK itself, see [CONTRIBUTING.md](CONTRIBUTING.md).
